# Online Bakery — Relational Database

A relational database project developed as part of the Database course at Lebanese International University.

## Overview

This project models the database of an online bakery, including customers, cakes, flavors, sizes, chefs, orders, payments, delivery, and related entities.

The database was planned and designed using an Entity-Relationship (ER) diagram and relational schema before being implemented in Microsoft SQL Server.

## Technologies

- Microsoft SQL Server
- SQL
- ER Modeling
- Relational Database Design

## Project Structure

- `Creation.sql` — Creates the database tables and relationships
- `Data.sql` — Inserts sample data into the database
- `Queries.sql` — Contains SQL queries addressing different business requirements
- `ER-Diagram-OnlineBakery` — Entity-Relationship diagram
- `Relations.HEIC` — Relational schema
- `Relations-2.HEIC` — Relational schema
